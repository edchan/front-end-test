# Front-End Demo

A front-end demo project built with **HTML**, **CSS + SASS**, **Javascript**, and **Vite**, showcasing my front-end development skills using this tech stack.

## Live Demo

[https://edchan.github.io/front-end-test/](https://edchan.github.io/front-end-test/)

## Tech Stack

- **HTML**
- **CSS + SASS**
- **Javascript**
- **Vite**

## Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher

## Installation + Local Development

1. **Clone the repository**
   ```bash
   git clone git@github.com:edchan/front-end-test.git
   cd front-end-test

2. **Install dependencies**
   ```bash
   npm run install

3. **Start the development server**
   ```bash
   npm run dev

3. **Open your bowser**
   ```bash
   http://localhost:5174/front-end-test/

## Build, Preview + Github Deployment

1. **Create a production build**
   ```bash
   npm run build

2. **Preview production build locally**
   ```bash
   npm run preview

3. **Open your bowser**
   ```bash
   http://localhost:4173/front-end-test/

4. **Deploy to github**
   ```bash
   npm run deploy

5. **Open your bowser**
   ```bash
   https://edchan.github.io/front-end-test/


## Available Scripts

- `npm run dev` – Start the local development server
- `npm run build` – Build the project for production
- `npm run preview` – Preview the production build locally
- `npm run deploy` – Deploy the prohect to Github Pages
